# 微信小程序

1. 在微信开发者工具中导入本目录 `miniprogram/`。
2. 开发阶段，修改 `app.js` 的 `API_BASE` 为电脑局域网 IP，例如 `http://192.168.1.10:5000/api`；真机不能访问 `127.0.0.1`。
3. 在开发者工具的「详情 → 本地设置」中勾选「不校验合法域名」。
4. 生产环境必须使用 HTTPS，并将 API 域名添加到小程序后台的 request 合法域名；把 `project.config.json` 中的 `appid` 改为实际 AppID。

当前已接入首页、搜索、食堂和档口、菜品评分、账号登录注册、打卡、个人中心，以及文字社区发帖与列表。图片发帖、点赞和评论发布、微信一键登录待下一阶段接入。
